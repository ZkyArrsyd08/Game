# Ikan Buntal (Godot 4.7)

Buka folder ini di Godot 4.7 lalu tekan F5 (main scene: `main.tscn`).

**Cara main**
- Gerak: kursor mouse / WASD / panah / geser jari (HP)
- Kembung: tahan klik / Spasi / klik kanan / tombol KEMBUNG (HP)
- Makan ikan kecil (hanya saat tidak kembung) untuk naik level dan membesar.
- Ikan pemangsa (tanda "!") menggigit kalau kamu tidak kembung. Kembung tepat waktu = durinya bikin mereka kabur (+skor).
- Ubur-ubur selalu menyengat. Gelembung udara mengisi meter udara.
- P / Esc untuk jeda.

Ikan pemain memakai sprite `assets/ikan_buntal.png`; sisanya digambar lewat kode di `main.gd`. Rekor tersimpan di `user://ikan_buntal.cfg`.
